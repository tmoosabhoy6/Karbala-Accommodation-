Connect the accommodation sheet

The Live tab shows the ACCOMMODATION tab of the Google sheet and updates by itself whenever the sheet changes. It needs a small connector that one person sets up once, signed in to a Google account that can open the sheet. After that, every device just works and no one has to sign in.

  1. Open script.google.com → New project.
  2. Delete what is in the editor and paste in the code from apps-script/Code.gs. Click Save.
  3. Click Deploy → New deployment, choose type Web app, set Execute as: Me and Who has access: Anyone, then Deploy and allow access.
  4. Copy the Web app URL and paste it here.

Full step-by-step guide: apps-script/README.md.

Saving on this device

Room changes are saved into the room list file on GitHub, so every phone and tab sees them. Each device that makes changes needs a GitHub key once.

  1. Open GitHub → new access key (signed in as the repository owner).
  2. Name it Karbala Rooms and choose an expiry date.
  3. Under Repository access, pick Only select repositories → Karbala-Accommodation-.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it here.

✓ Saving is on for this device.

To set up another phone without making a new key, copy this device's link and open it there once. Anyone with that link can change the room list, so only send it to people who should.
